# SlimBadge-C6 Lite 极简版 (高性价比)

## 1. 版本定位与成本
- **定位**：低成本、极简硬件架构，保留核心墨水屏显示、ESP32-C6 Wi-Fi 6/BLE无线控制与基础锂电充放电。
- **BOM 器件数**：31 项 (移除 PD 诱骗芯片 CH224K，替换为侧按微动开关与镀金测试焊盘矩阵)。
- **单套预估成本**：约 ¥39.39（控制在 ¥40 以内，极具批量与个人打样优势）。

## 2. 关键硬件变更说明
1. **移除 CH224K PD 诱骗芯片**：
   - 标配 USB Type-C 5.1k 下拉电阻，任意常规 5V 充电头/充电宝均可稳定输出 5V（可达 3A/15W 供电能力）。
   - 彻底避免外壳内部升压/降压的高温发热损耗，系统更冷、更安全。
2. **新增侧按微动轻触按键 (SW2)**：
   - 采用标准超薄侧按轻触开关 `SW_SPST_B3U-3000P`（LCSC: C135850），放置于板边顶部 ($X=13.5, Y=1.7$)。
   - 按键轴心凸出板边 0.25mm，实现真正的**侧边按压（侧按）**，避免从背面 PCB 表面按压的不便，手感清脆。
   - 信号直连 `GPIO9` (ESP32-C6 硬件 Bootloader 引导与用户交互)，兼顾刷机救砖与日常墨水屏切页/刷新功能。
3. **新增 6 位镀金调试测试焊盘矩阵 (TP1 ~ TP6)**：
   - 利用移除芯片后留出的空白区域构建：
     - `TP1`: VBUS (5V 输入)
     - `TP2`: GND (地)
     - `TP3`: 3V3 (系统 3.3V 逻辑电源)
     - `TP4`: GND (地)
     - `TP5`: BAT (电池端电压)
     - `TP6`: BOOT / GPIO9 (调试引导)
4. **板载 SPI Flash (U12)**：
   - 完备 3D 封装与物理元器件渲染 (SOIC-8)。
