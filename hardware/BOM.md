## 🔍 关键器件选型背景与硬核避坑总结 (来自原型实测实录)

### 1. 墨水屏来源与 25 元捡漏背景
- **原厂出身**: 本项目采用的 3.98 寸四色电子纸，来源于**华为生态智能四色墨水屏手机壳（如 Porink Pixel / ReinkCase）拆机/尾货库存**。原手机壳官方指导价普遍高达 **300+ 元**。
- **捡漏现状**: 伴随旧款手机换代，海量原装正品尾货屏幕清库存，**仅需 20~25 元即可包邮入手**。
- **物理规格**: 型号为 `SE0398NZ07-FNG-A0` 或 `A1` 批次，物理分辨率为 **768 × 552**，屏幕内部驱动 IC 为 SSD1683。屏幕排线为 24-Pin 0.8mm 间距焊接式金手指。

### 2. ⚠️ 致命避坑：为什么普通墨水屏驱动板无法点亮？
- 市面上常见的微雪或通用 24-Pin 驱动板，绝大多数是针对 2.13"/2.9" 的单色、双色或小三色屏设计的，板载升压回路一般仅输出 +15V / -15V。
- **3.98 寸 BWRY 四色电泳微胶囊需要极高的物理驱动电场**：
  - **VGH (正偏压)**: 需稳定达到 **+22V**；
  - **VGL (负偏压)**: 需稳定达到 **-20V**；
  - **VSH1 / VSH2 (驱动正高压)**: 需达到 **+15V**。
- 如果强行使用普通驱动板，当执行到上电升压指令 (`Power On 0x04`) 时，由于储能电感与二极管耐压不足无法达到设定阈值，**BUSY 引脚将永久死锁为低电平**，或出现大面积缺色、严重拖尾。
- **解决方案**: 务必采用带有足额功率储能电感与高耐压肖特基二极管的高压驱动转接板（推荐立创开源硬件平台 OSHWHub @flamj0 的开源转接驱动板方案）。

### 3. 🧠 屏幕逆向底层：A0 / A1 物理栅极交错扫描机制
- 控制器内部 RAM 寻址为 **768 × 600**，但物理可视区域仅为 **768 × 552**。
- **物理面板并不是顺序行扫描**，而是由左右两侧的 Gate Driver 进行奇偶交错物理栅极寻址。若按常规线性写入，图片会被切碎成交错混沌条纹。
- 本项目固件（Rust 及原型 MicroPython）内部均已集成完整的 A0/A1 栅极交错映射矩阵，支持自动零内存转换。

### 4. 电池尺寸与容量选择
- **外壳三明治内胆预留空间**: 电池仓极限尺寸为 **663535**（即厚度 ≤ 6.6mm，宽度 ≤ 35mm，长度 ≤ 35mm）。
- **最佳推荐型号**: **663032 (3.7V 750mAh，带保护板)**。
  - 尺寸为 6.6mm × 30mm × 32mm，完美放入电池仓且留有适度缓冲余量，绝不挤压膨胀。
  - 墨水屏静态显示零耗电，配合 ESP32-C3 深度休眠，750mAh 电池按每日刷新 1~2 次计算，**续航可达 6 至 12 个月**。

### 5. 三明治结构与 8 颗螺母紧固体系
- 外壳采用 **前盖 + 中框 + 后盖** 的三明治三层夹层结构，整体强度极高且方便独立拆装：
  - **前盖 4 颗 M2 铜螺母**: 用电烙铁热熔压入前盖内侧 4 处定位柱中；
  - **中框 4 颗 M2 铜螺母**: 热熔压入中框背面沉孔中；
  - 组装时，先从中框向前拧入 4 颗 M2×6mm 螺丝固定前盖与墨水屏；再安装主控与电池，最后从后盖沉头孔拧入 4 颗 M2×8~10mm 螺丝锁死中框。整机无外露卡扣，缝隙均匀紧实。

### 6. NFC 芯片选型：为什么必须是 NTAG216？
- **容量对比**: NTAG213 仅 144 字节可用容量；NTAG215 为 504 字节；而 **NTAG216 拥有高达 888 字节可用容量**。
- **社交与随身应用**: 888 字节能从容存储：
  - 完整的海外社交电子名片 (vCard 格式：包含姓名、头像短链、Telegram / Discord / X (Twitter) / GitHub 账号、个人主页)；
  - 离线 WebBLE PWA 直达链接 (`https://<your-badge>.pages.dev`)，他人手机轻碰后盖即可直接调起 Chrome 进行无线配对与传图；
  - 备用局域网 Wi-Fi 配网 Token。

## 🧰 必备装配工具清单

1. **电烙铁 / 焊台**:
   - 焊接 ESP32-C3、TP4056、滑动开关与电池引线；
   - 调温至 260°C ~ 280°C，用于将 8 颗 M2 滚花铜螺母平整压入前盖与中框。
2. **PH1 十字螺丝刀 / 1.5mm 内六角扳手**: 用于紧固 8 颗 M2 机械螺丝。
3. **耐温绝缘高温胶带 (Kapton)**: 用于电池表面与 PCB 背面绝缘保护。
4. **0.3mm 超薄无痕双面胶 / 泡棉胶**: 用于将墨水屏四周稳固贴合在前中框沉台上。
5. **3D 打印机 (FDM 或 SLA/光敏树脂)**:
   - 推荐打印材料: **PETG / PLA+ / ABS** (层高 0.12~0.16mm，3 层外壳，100% 填充)；
   - 打印文件位于本仓库 `hardware/3d_models/`。
