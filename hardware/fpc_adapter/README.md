# 华为/荣耀 3.98英寸墨水屏转接排线 (24-Pin 0.8mm 焊接 转 0.5mm 插接)

> **适用屏幕**：华为 3.98英寸 手机壳拆机墨水屏 (`SE0398NZ07-FNG-A0` / `JY_DC24_NFC_V1.0`)  
> **转接目标**：通用 24P 0.5mm 间距下接翻盖 FPC 连接器
> **设计软件**：KiCad 10.0+ (向下兼容 KiCad 8/9)  
> **DRC 状态**：0 Errors, 0 Warnings, 0 Unconnected Pads

---

## 🛠️ 设计改良特性

1. **45° 仿形外形 (Contour Outline)**：
   - 移除原先直角两侧多余无走线的死基材，外框完全沿 45° 扇出走线平滑收拢，轻量美观。
2. **插舌与金手指精密适配 (J_ZIF)**：
   - 插舌宽度严格控制在 **12.50 mm**，前端带有 **0.3 mm × 45° 导向倒角**，插拔顺畅不卡壳。
   - 金手指长度加长至 **3.20 mm**（原 1.8mm），确保在任意 0.5mm ZIF 翻盖插座中弹片均能可靠接触。
   - 采用整排开窗（Gang Mask Opening，无开窗桥），彻底解决 0.2mm 窄间隙覆盖膜起翘与毛刺问题。
3. **消除冗余底层铜皮**：
   - 完全清理了原先底层未连接走线的 24 个冗余焊盘，避免热应力翘曲及寄生耦合。
4. **PI 补强层定义 (User.1 / Stiffener)**：
   - **插舌背面**：`12.50 mm × 3.50 mm` PI 补强片（建议选择 0.15~0.20mm PI，加上 0.11mm 板厚总计约 0.3mm，完美卡紧）。
   - **焊接端背面**：`20.40 mm × 3.50 mm` 耐热 PI 补强片，方便手工电烙铁焊接与支撑。
5. **极客风格丝印 (SilkScreen)**：
   - 正面标注 `[ ZGQ Inc. ]`、`EPD 24P: SOLDER > ZIF`、`HW 3.98" SCREEN ADAPTER`。
   - 醒目标注两端 `1`、`24` 脚位与常用引脚功能标识，且全部严格位于板框安全间距内。
6. **嘉立创双面 FPC 0元体验券原生兼容**：
   - 导出文件包含完整的顶层与底层层叠定义，嘉立创自动识别为双面板，完美享受官方“双面 FPC 免费券（含 1 种 PI 补强免单）”。
