# 3D 打印外壳与硬件结构设计指南 (Hardware & Enclosure)

本目录包含 3.98 英寸四色电子墨水屏随身工牌 & 兽聚痛卡的全部 3D 打印外壳 STL 模型、OpenSCAD 参数化源码、Python 网格构建脚本以及 FPC 屏幕转接板工程。

---

## 📁 目录结构说明

```text
hardware/
├── BOM.md                  -> 详细元器件选型与物料采购清单
├── 3d_models/              -> 3D 打印即用型 STL 文件与 OpenSCAD 源码
│   ├── case_front.stl      -> 前框 (正面 6.9mm 窄边框，M2 铜螺母预埋孔)
│   ├── case_middle.stl     -> 中框主体 (FPC侧与开关对面底壁双向双挂绳孔 1.5mm，支持横屏/竖屏挂绳，正面 25mm NFC 槽，双 Type-C 开孔，开关滑轨与 'O'/`|` 标识)
│   ├── case_back.stl       -> 标准后盖 (FPC 侧居中 25mm NFC 槽，4 个磁铁沉孔，电池防挤压 R7 圆角)

│   ├── acrylic_template.stl-> 91.0 × 64.0 × 1.5 mm 亚克力视窗 1:1 划线/切割辅助治具
│   └── epd_case.scad       -> 完整的 OpenSCAD 参数化建模源码
├── scripts/
│   └── build_epd_case.py   -> Python 3D 网格生成脚本 (纯数学算法 + Delaunay 三角剖分)
└── fpc_adapter/            -> 24-Pin 0.8mm 转 0.5mm 45° 转接板工程（已作废归档，现采用 OSHWHub flamj0 高压驱动板）
```

> ⚠️ **关于转接板作废归档说明**：  
> 原自制 45° FPC 转接排线工程仅完成物理引脚间距转换（0.8mm 转 0.5mm），而 3.98" 四色屏（`SE0398NZ07`）需要高达 +22V / -20V / +15V 物理驱动偏压，普通驱动板无法正常工作。因此自制转接板已作废归档，硬件推荐采用立创开源硬件平台 [@flamj0 的墨水屏 FPC 转接板](https://oshwhub.com/flamj0/mo-shui-ping-fpc-zhuan-jie-ban)。

## 🔌 电气接线与焊接工艺指南 (Wiring & Soldering Guide)

整机电气系统由 **3.98" 四色墨水屏**、**高压转接驱动板**、**ESP32-C3 SuperMini 核心板**、**TP4056 充电保护板**、**3.7V 聚合物锂电池** 以及 **微型滑动开关** 组成。

---

### 1. 墨水屏 24-Pin 0.8mm FPC 焊接工艺与避坑指南 ⚠️

华为拆机四色墨水屏（`SE0398NZ07`）排线为 **24-Pin、0.8mm 间距** 的裸铜金手指，需贴焊至驱动板对应焊盘：

* **焊接工艺要求**：
  * **必须采用表面贴装回流焊**：推荐在驱动板排线焊盘上均匀涂抹微量中低温锡膏（如 Sn42Bi58 或 Sn63Pb37），排线金手指精确对准 24 个引脚后，使用**恒温加热台**（推荐温度 200℃~230℃）平放加温熔锡，或使用**热风枪**（风量调小，300℃ 悬空 5cm 环形微风扫吹）均匀受热贴焊。
  * **严禁普通电烙铁大面积暴力拖焊**：0.8mm 间距极为密集，烙铁手工拖焊极易导致引脚间微细锡桥短路；且烙铁头长时间高温接触极易烫坏 FPC 柔性聚酰亚胺薄膜基底，造成排线起泡变形或焊盘剥离报废。
* **💡 新手极力推荐方案 —— 嘉立创 JLC SMT 贴片加工**：
  * 如果你不擅长密脚手工焊接，或者手头没有恒温加热台/热风枪等回流焊工具，**强烈建议在嘉立创（JLC）打样驱动板 PCB 时，直接勾选 JLC SMT 贴片加工服务**，由工厂自动化高精度贴片机代焊，免去手焊烦恼，焊点饱满平整，一次点亮良品率高！

### 2. ESP32-C3 SuperMini 与高压驱动板连线对照表 (8 线 SPI)

驱动板与 ESP32-C3 SuperMini 之间通过 8 根细跳线（推荐 30AWG 或 32AWG 耐高温硅胶线 / OK线）连接，引脚定义与底层硬件 SPI/GPIO 配置严格对应：

| ESP32-C3 SuperMini 引脚 | 驱动板 (Driver Board) 引脚 | 信号名称 / 作用 | 信号流向 | 底层驱动与硬件逻辑说明 |
| :---: | :---: | :--- | :---: | :--- |
| **`3.3`** | **`VCC`** | 3.3V 逻辑与高压升压供电 | ESP32 → 驱动板 | 主控板载 3.3V LDO 稳压输出，为驱动板控制逻辑和升压储能电感供电 |
| **`G`** | **`GND`** | 系统参考地 | 共通 | 必须与系统总地回路保持极低阻抗连接 |
| **`6`** (GPIO 6) | **`DIN`** | SPI MOSI 数据输出 | ESP32 → 驱动板 | ESP32-C3 硬件 SPI2 (FSPI) 主机数据输出，传输寄存器命令与图片显存 |
| **`4`** (GPIO 4) | **`SCK`** | SPI SCLK 串行时钟 | ESP32 → 驱动板 | 硬件 SPI 串行时钟线 (固件配置为 8MHz 高速传输) |
| **`7`** (GPIO 7) | **`CS`** | 片选使能 (Chip Select) | ESP32 → 驱动板 | 低电平有效，选中屏幕驱动 IC 允许进行 SPI 通信 |
| **`1`** (GPIO 1) | **`DC`** | 数据/命令选择 (Data/Command)| ESP32 → 驱动板 | 低电平 = 传输命令寄存器地址；高电平 = 传输参数或显示显存 |
| **`2`** (GPIO 2) | **`RST`** | 硬件复位引脚 (Reset) | ESP32 → 驱动板 | 低电平产生硬件复位脉冲，唤醒或重置驱动 IC 初始状态 |
| **`10`** (GPIO 10) | **`BSY`** | 状态忙检测 (BUSY) | 驱动板 → ESP32 | 输入引脚 (内部弱上拉)；高电平 = 空闲就绪；低电平 = 升压或物理刷新中 |

> 📌 **飞线工艺建议**：跳线长度裁剪至 35~45mm 最佳，走线尽量平整贴合槽底。焊接完毕后建议使用少量 UV 绝缘绿油固化，或贴上耐高温 Kapton 绝缘胶带加固，防止外壳震动产生引脚短路。

### 3. TP4056 充电板、锂电池、滑动开关与主控供电回路

整机电源管理架构采用“独立充电管理 + 机械硬切断 + LDO 二次稳压”闭环设计：

```text
       ┌───────────────┐
       │ 3.7V 锂电池   │
       │ (带保护板)    │
       └──┬─────────┬──┘
      红线(+)     黑线(-)
          │         │
          ▼         ▼
       ┌──┴─────────┴──┐
       │ B+         B- │
       │    TP4056     │
       │  充电管理板   │
       │ OUT+     OUT- │
       └──┬─────────┬──┘
          │         │
          │         └─────────────────────────┐ (系统总地 GND)
          ▼                                   ▼
    ┌───────────┐                         ┌───────┐
    │ 微型滑动  │                         │       │
    │ 开关 (SW) │                         │       │
    └──┬────────┘                         │       │
       │ (拨至 ON 导通)                   │       │
       ▼                                  │ESP32- │
    ┌───────┐                             │  C3   │
    │  5V   │ ──────────────────────────> │ Super │
    │ (VIN) │                             │ Mini  │
    └───────┘                             │       │
                                          │   G   │ ◄─── (接 OUT-)
                                          └───────┘
```

#### 详细接线步骤：
1. **锂电池接入 TP4056**：
   - 锂电池红线（正极 `+`）焊接至 TP4056 的 **`B+`** 焊盘；
   - 锂电池黑线（负极 `-`）焊接至 TP4056 的 **`B-`** 焊盘。
2. **系统总接地**：
   - 将 TP4056 的 **`OUT-`** 焊盘直接焊接至 ESP32-C3 SuperMini 的 **`G` (GND)** 引脚。
3. **总电源开关控制**：
   - 从 TP4056 的 **`OUT+`** 焊盘引出一根细线，焊接至微型滑动开关（SS12D00 / SS12F15）的**中心公共引脚**（Pin 2）；
   - 从滑动开关的**常开引脚**（拨向 `|` 侧导通的引脚，Pin 1 或 Pin 3）引出一根细线，焊接至 ESP32-C3 SuperMini 的 **`5V` (VBUS/VIN)** 引脚。
4. **工作逻辑与安全性**：
   - **机械硬切断**：开关拨至 `O`（断开）时，主控与墨水屏驱动芯片彻底断电，静态待机电流为纯物理 **0 μA**，即便长期闲置数年也不会亏电损坏电池。
   - **独立充电逻辑**：当插入侧边 TP4056 Type-C 充电线时，无论电源开关处于开（ON）还是关（OFF）状态，TP4056 都会安全地为锂电池进行恒流-恒压充电，红灯常亮表示充电中，蓝灯/绿灯常亮表示已充满。
   - **双 Type-C 职责分明**：
     * **侧面 Type-C (TP4056)**：日常充电源接口，支持 5V/1A 安全充电；
     * **顶部 Type-C (ESP32-C3)**：开发固件烧录、串口日志调试与 WebUSB 直连接口。

### 4. ⚡ 上电前检测与防翻车清单 (Checklist)

在拧紧螺丝盖上后盖之前，**务必执行以下电气检查**：
1. **万用表蜂鸣档测短路**：
   - 测量 ESP32-C3 的 `3.3` 与 `G` 之间是否短路（阻值应 > 1kΩ，蜂鸣器不应长鸣）；
   - 测量 ESP32-C3 的 `5V` 与 `G` 之间是否短路；
   - 测量电池 `B+` 与 `B-` 是否有反接或虚焊。
2. **首次通电测试**：
   - 拨动滑动开关至 `|` (ON)，观察 ESP32-C3 板载蓝色/红色电源指示灯是否点亮；
   - 此时 ESP32-C3 启动并发射 `EPD-Display` Wi-Fi AP 与蓝牙广播，屏幕会执行一次出厂/上电初始化刷新。若屏幕能正常完成黑白红黄全刷且无花屏条纹，说明 24-Pin FPC 与 8 线 SPI 接线 100% 正确！
3. **绝缘隔离**：
   - 在电池表面贴一层耐高温 Kapton 绝缘胶带，防止电池金属铝塑壳与 ESP32-C3 或驱动板背面的凸出焊点摩擦刺破短路。

## 🔧 装配步骤示意

1. **热熔螺母安装**:
   - 取 8 颗 M2 铜螺母（外径 3.2mm，高 3.0~3.5mm），使用电烙铁压头（温度 260~280℃）分别垂直压入 `case_front.stl` 背面的 4 个定位孔与 `case_middle.stl` 背面的 4 个沉孔座，轻压热熔至与塑料表面平齐。
2. **安装保护视窗与墨水屏**:
   - 依据 `acrylic_template.stl` 切割好 91.0×64.0×1.5mm 的透明亚克力板，嵌入口框内；
   - 按照前文工艺完成墨水屏 24-Pin FPC 与高压驱动板的贴片焊接；
   - 将 3.98" 墨水屏正面四周贴好 0.3mm 超薄双面胶（9448A 或 VHB），滑入中框开槽，居中粘合在中框正面；
   - 将驱动板 FPC 背面贴好双面胶粘合在限位槽内。
3. **电气焊接与中框组件安装**:
   - 参照【电气接线与焊接工艺指南】，用细飞线完成 ESP32-C3、驱动板、TP4056、微型滑动开关与锂电池的全部焊线；
   - 将微型滑动开关卡入中框顶部开关位，同时将 3D 打印推钮 `switch_cap.stl` 套在开关手柄上；
   - 固定 ESP32-C3 SuperMini 与 TP4056 充电板，背面贴好薄双面胶卡入限位槽并粘合，确保两个 Type-C 接口分别居中露出；
   - 用万用表排查短路后，拨开开关完成首次上电亮屏测试。
4. **NFC 贴片与磁铁装配**:
   - 中框正面中心凹槽粘贴第 1 枚 NTAG216 NFC 贴片；
   - 后盖排线侧半边中心凹槽粘贴第 2 枚抗金属 NTAG216 NFC 贴片；
   - 后盖内侧 4 个沉孔内分别压入 4 颗 N52 强力磁铁（6.0×1.2mm），可用少量 UV 胶或瞬干胶固定。
5. **合盖紧固**:
   - 将后盖对齐中框，确保滑动推钮防脱卡块嵌入后盖限位槽内；
   - 从中框正面拧入 4 颗 M2×6mm 螺丝固定前盖与中框；
   - 从后盖正面沉孔拧入 4 颗 M2×8~10mm 沉头机械螺丝锁紧中框完成总装。
